# Liepa 🌿

Liepos dienoraštis: maitinimai (krūtis su laikmačiu, buteliukas, papildomas maistas), miegas ir pogulis, pieno nutraukimas, sauskelnės. Patarimai pagal amžių ir įrašus. Duomenys sinchronizuojami tarp abiejų tėvų telefonų per Google Sheet (`backend/Code.gs`).

Programėlė: https://tomule1urbule.github.io/liepa/
